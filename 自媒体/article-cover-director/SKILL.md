# 文章封面策划

## 核心原则

封面先解决识别和点击，再谈风格。它应该让读者立刻知道主题、对象和收益，不能只生成漂亮但不传达信息的图。

## 使用时机

- 用户要给文章、小红书笔记、公众号推文或微博内容生成封面。
- 用户需要封面标题、画面方向、构图、字体层级或图片生成提示词。
- 用户已有稳定图片生成能力，但需要更好的封面 brief。

## 工作步骤

1. 从文章或总导演 Brief 中提取读者、主题、情绪和点击理由。
2. 写 3 个封面方向：信息型、场景型、冲突型；说明取舍。
3. 选推荐方向，给出封面主标题、副标题和必要角标。
4. 写画面 brief：主体、背景、构图、色彩、字体、材质、留白。
5. 写图片生成提示词；如果用户要求实际生成，再调用当前环境可用的图片生成能力。
6. 做封面检查：文字是否过长、是否误导、是否能在小屏识别。

```md

## 推荐封面

- 副标题：
- 画面主体：
- 构图：
- 色彩：
- 字体层级：
- 不要出现：

## 图片生成提示词

...
```

## 边界

- 这个 Skill 负责封面策划和提示词，不等同于安装通用图片生成 Skill。
- 不使用难以阅读的小字、长句或复杂表格当封面主体。
- 不伪造官方背书、真实用户评价、数据截图或聊天记录。
