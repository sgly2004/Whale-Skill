# 真实文献追溯

用本 skill 把模糊的文献需求，转成**有选择理由、有可核验链接**的真实论文集合。

## 适用场景

当用户需要以下任一能力时使用：

- 找真实存在的论文，而不是编造引用
- 返回用户可自行核验的文献地址
- 筛掉弱相关、重复、难核验的文献
- 构建文献综述用的核心文献列表
- 收集带发表痕迹的近期论文
- 中英文文献混检，且来源清晰
- 尽量返回 CNKI 链接；否则给出 DOI、出版社页或其他 canonical 页面
- 从 Google Scholar、顶刊、顶会中发现高质量国外文献

## 主要信息源

使用这些信息源时，优先打开**内置浏览器**访问（如果有api更优先用api）。若站点需要登录且用户尚未登录，**提示用户先登录**，再继续检索。

### 第一层级：papers.cool（最优先）

国际文献最优先使用 **https://papers.cool/**。

**分支选择逻辑：**

- 若用户只要**已发表论文（顶会顶刊）**，选择 **Venue** 分支并指定具体会议/期刊
- 若用户允许**预印本**，选择 **arXiv** 分支，或两者混检
- 不确定时明确询问用户：

  > 「你需要只搜索已发表的论文（顶会顶刊，Venue），还是也包括预印本（arXiv）？」

**papers.cool 可用 venue（23 个）：**
AAAI, ACL, COLM, COLT, CoRL, CVPR, ECCV, EMNLP, ICCV, ICLR, ICML, IJCAI, INTERSPEECH, IWSLT, MICCAI, MLSYS, NAACL, NDSS, NeurIPS, OSDI, UAI, USENIX-Fast, USENIX-Sec

### 第二层级：论文仓库（原始来源）

第一层级不足时，使用各论文仓库直接检索：

| 源 | URL | 用途 |
|----|-----|------|
| **arXiv** | https://arxiv.org/ | 预印本 |
| **Semantic Scholar** | https://www.semanticscholar.org/ | 广覆盖检索、引用、相似论文 |
| **Hugging Face Papers** | https://huggingface.co/papers | 社区热度 |
| **OpenReview** | https://openreview.net/ | 顶会在投/已审、review 信号 |
| **OpenAlex** | https://openalex.org/ | 开放索引、主题/作者筛选 |

### 第三层级：论文网络挖掘

需要从 seed 论文扩展、做引用网络或关系挖掘时使用：

| 工具 | URL | 用途 |
|------|-----|------|
| **Inciteful** | https://inciteful.xyz/ | 引用路径、跨领域连接 |
| **Connected Papers** | https://www.connectedpapers.com/ | 共引与书目耦合图谱 |
| **ResearchRabbit** | https://www.researchrabbit.ai/ | 多 seed 迭代扩展 |
| **Consensus** | https://consensus.app/ | 证据问答：「有没有研究表明 X」 |
| **Scite** | https://scite.ai/ | 引用类型：supporting / contrasting |

## 国外文献策略

用户要国外文献或中英文混检时，分两轮进行：

1. 发现轮
   - 用 Google Scholar 风格发现或等价检索结果得到候选论文
   - 必要时在期刊、会议、预印本中扩大检索面
2. 核验轮
   - 在出版社页、DOI 页或官方 proceedings 页逐条核验
   - 优先 canonical landing page，而不是搜索结果页

国外文献排序时，优先考虑：

- 领域内顶刊
- 领域内顶会
- 带 DOI 或 proceedings 元数据的出版社页
- 仅在出版社页不可用时，才用稳定的机构仓储页

不要只因论文出现在 Google Scholar 就视为高质量。Scholar 只用于发现，最终必须落到官方来源核验。

## 默认假设

用户未说明时，采用以下默认值，并在检索前简要声明：

- 默认关注近 **5 年**，除非主题偏经典或用户要求更长区间
- 普通文献集目标 **12–18 篇**
- 优先可追溯来源，而不是数量更大但来源更弱的集合
- 中文主题或用户要中文文献时，优先 CNKI 可追溯
- 国外或混检时，优先顶刊顶会
- 默认用**中文**回复，除非用户要求其他语言

## 范围收窄

主题模糊时，不要直接大范围搜索。

若用户说：

- `帮我找文献`
- `搜一些论文`
- `做文献综述`
- `筛选优秀文献`
- `给我真实文献地址`
- 只给宽泛主题、没有任务/场景/时间窗

则先收窄需求。

只问最关键缺失信息：

- 具体子主题或应用方向
- 中文、英文还是混检
- 只要近期，还是经典 + 近期
- 需要多少篇
- 是否必须 CNKI 可追溯

若一轮沟通后仍模糊，选一个合理解释，明确说明后继续。

## 检索工作流

按以下顺序执行。

### 1. 重述工作范围

检索前用 2–5 行重述已确认范围：

- 主题边界
- 时间窗口
- 数据源偏好
- 目标篇数
- 输出格式

### 2. 制定检索计划

准备小规模双语关键词集：

- 3–6 组中文关键词
- 3–6 组英文关键词
- 若干组合，覆盖 task、method、dataset、scenario

宽主题拆成子主题，避免结果重复。

用户要国外文献时，加入 venue-aware 检索词，例如：

- 会议名
- 期刊系列名
- 方法关键词
- 任务关键词

示例：

- `spacecraft pursuit evasion game IEEE TAC`
- `orbital pursuit evasion game AIAA`
- `differential game spacecraft Automatica`

### 3. 按可追溯性检索

**以 papers.cool 为主要工具：**

1. 打开 https://papers.cool/
2. 按用户偏好选择 Venue 或 arXiv 分支
3. 用准备好的关键词进行站内检索
4. 按相关性与日期浏览结果

**兜底来源（按顺序）：**

- 国外文献：Crossref、DOI 页、出版社页或官方 proceedings 页
- 中文文献：CNKI 或 CNKI 可达记录
- 仅在无法确认官方页时，Google Scholar 才作为发现参考

国外文献筛选时，venue 质量是检索计划的一部分：

- 优先领域内顶刊顶会
- 在备注中区分期刊论文与会议论文
- 预印本标注为 provisional，除非已有正式发表版

**未说明来源与核验方式前，不要把论文放入最终集合。**

### 4. 筛选候选集

优先保留满足以下大部分条件的论文：

- 与收窄后主题强相关
- 落在目标时间窗口内
- 方法上有代表性或影响力
- 来自可信 venue
- 国外文献来自被认可的期刊或会议，且有稳定官方页
- 适合综述、比较表或 related work
- 可追溯到真实页面或记录

拒绝以下论文：

- 重复或近重复
- 过于泛化，无法支撑目标主题
- 元数据不足以核验
- 质量低或明显偏题

### 5. 核验链接

每篇入选论文，按以下顺序返回最佳地址：

1. canonical 出版社页或 DOI 页
2. 可用的 CNKI 记录或 CNKI 落地页
3. 其他稳定官方页
4. 仅在无法确认官方页时，Google Scholar 作为发现参考

链接无法确认时，写 `待核验`，不要猜测。

### 6. 输出最终集合

每篇论文至少包含：

- 题目
- 作者
- 年份
- 期刊/会议
- 选择理由
- 文献状态，如 `strong`、`selected`、`backup`
- canonical 链接
- CNKI 链接（如有）
- DOI（如有）
- 不确定性备注

## 筛选分级

采用实用分级：

- `A`：高度相关、易核验的核心论文
- `B`：良好支撑论文
- `C`：备用论文，可能仍有价值
- `S`：国外顶刊顶会中，高度相关且影响力突出的论文

相似论文之间，优先：

- 主题贴合度更高
- 方法或贡献更清晰
- venue 更强或来源更稳定
- 链接更易核验
- 国外论文 venue 声誉与 official traceability 更好

不要过度依赖引用数。较新但更精确的论文，可能优于较老但较泛的论文。

## 输出格式

用户要论文列表时，默认用表格。

推荐列：

- 序号
- 文献题目
- 作者
- 年份
- 期刊/会议
- 选择理由
- 质量等级
- 真实地址
- CNKI地址
- DOI
- 谷歌学术/Scholar
- 备注

用户要综述或 related work 时，在最终集合上归纳：

- 研究主题
- 主要方法
- 空白或局限
- 建议引用顺序

## 质量规则

- 绝不伪造论文题目、DOI、CNKI 链接、出版社页。
- 绝不隐瞒不确定性；未核验链接必须标注。
- 宁可少给，也要保证真实可追溯。
- 主题宽泛时，先解释收窄选择再检索。
- 中文文献以 CNKI 可追溯为筛选逻辑的一部分。
- 国外文献以 venue 质量与 official provenance 为筛选逻辑的一部分。

## 推荐回复模式

1. 确认范围。
2. 按广到窄检索。
3. 按相关性与可信度筛选。
4. 核验链接。
5. 返回带选择理由与可追溯地址的最终论文集合。
