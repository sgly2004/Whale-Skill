# 图卡拆解

## 核心原则

图卡不是把文章切段截图。每张卡只承担一个传播任务：吸引、解释、证明、推进或转化。

## 使用时机

- 用户要把文章拆成小红书图卡。
- 用户要从长文生成轮播图脚本。
- 用户要封面、内页、结尾页的文案和视觉说明。
- 用户要把活动、产品、教程或复盘做成可设计的卡片清单。

## 工作步骤

1. 先确认平台和目标动作；默认适配小红书轮播图。
2. 确定卡片数量，优先 6-9 张；内容很轻时减少，不硬凑。
3. 设计叙事顺序：封面钩子、痛点/场景、核心信息、证据/例子、行动。
4. 给每张卡写短标题、正文、视觉建议和素材需求。
5. 控制文字密度：移动端一眼能扫完，不把正文塞进图里。
6. 给设计或图片生成环节留下明确画面指令。

## 输出模板

```md
## 图卡策略

- 平台：
- 卡片数量：
- 目标动作：
- 视觉基调：

| 卡片 | 任务 | 标题 | 正文 | 视觉 | 素材/备注 |
| --- | --- | --- | --- | --- | --- |
| 1 | 封面钩子 |  |  |  |  |
| 2 | 场景/痛点 |  |  |  |  |
| 3 | 核心观点 |  |  |  |  |

## 结尾页 CTA

...
```

## 质量门槛

- 第一张必须能独立成立，不能只有抽象口号。
- 中间卡不能重复同一个信息点。
- 结尾页要有明确动作，但不能诱导违规互动。
- 涉及真实用户、聊天记录、照片时必须处理隐私和授权。
